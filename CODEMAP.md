# Code Map

## Overview

This document provides a quick reference to all files in the Whot card library, their responsibilities, and relationships.

## Source Files (`src/`)

### Core Files

| File | Purpose | Dependencies | Exports |
|------|---------|--------------|---------|
| `index.ts` | Main entry point, public API exports | All modules | Public API |
| `types.ts` | TypeScript type definitions | None | All public types |

| `rng.ts` | Seeded random number generator | None | `SeededRNG`, `createRNG` |

## Key Responsibilities

### Deck Management
- **`deck.ts`**: Core deck logic, card operations, serialization
- **`rng.ts`**: Deterministic shuffling with seeded random numbers
- **`types.ts`**: Card and deck type definitions

### Rendering System
- **`render-card.ts`**: Main rendering API, backend selection
- **`layout.ts`**: Theme system, layout constants, deck composition
- **`svg.ts`**: SVG string manipulation, accessibility helpers
- **`suit-symbols.ts`**: Programmatic symbol generation
- **`assets/templates.ts`**: SVG template storage

### Build & Configuration
- **`rollup.config.mjs`**: Production builds, minification, obfuscation
- **`tsconfig.json`**: TypeScript strict mode, module resolution
- **`.eslintrc.cjs`**: Code quality, Google style guide compliance
- **`vitest.config.ts`**: Testing framework, coverage reporting

## File Naming Conventions

- **`.ts`**: TypeScript source files
- **`.spec.ts`**: Test files
- **`.d.ts`**: TypeScript declaration files
- **`.config.ts`**: Configuration files
- **`.cjs`**: CommonJS configuration files
- **`.mjs`**: ES module configuration files

## Extension Points

### Adding New Suits
1. Update `types.ts` - add to `Suit` type
2. Add template to `assets/templates.ts`
3. Add symbol generator to `suit-symbols.ts`
4. Update composition in `layout.ts`
5. Add tests in `render.spec.ts`

### Custom Themes
1. Extend `WhotTheme` interface in `types.ts`
2. Update `mergeTheme` in `layout.ts`
3. Apply in rendering functions
4. Add theme tests

### New Rendering Backends
1. Create backend file in `render/`
2. Add to backend selection in `render-card.ts`
3. Update `RenderOptions` type
4. Add backend-specific tests
